# Лабораторна робота №4: Отримання та аналіз даних про вразливості через NVD API

CLI-утиліта на Python для отримання інформації про вразливості (CVE) з офіційного NVD API v2.0 або з локального JSON-файлу, валідації структури відповіді та оцінки критичності за правилами **Варіанта 2**.

## Правило аналізу (Варіант 2)

- **Поріг оцінки (`threshold`):** `baseScore >= 8.0` (CVSS v3.1, пріоритет метрики `Primary`)
- **Поле метрики (`field`):** `attackComplexity`
- **Очікуване значення (`expected`):** `"LOW"`
- **Можливі рішення (`decision`):**
  - `review` — статус не `Rejected`, знайдено валідну CVSS v3.1 оцінку, `score >= 8.0` та `attackComplexity == "LOW"`.
  - `other` — дані повні, але умова порогу або значення `attackComplexity` не виконується.
  - `not_found` — запис для вказаного CVE відсутній у відповіді (`vulnerabilities` порожній).
  - `rejected` — вразливість має статус `Rejected`.
  - `insufficient_data` — відсутня оцінка CVSS v3.1 або поле `attackComplexity`.

## Структура проєкту

```text
labs/lab04/

    └── test_main.py       # Тести CLI інтерфейсу (capsys, tmp_path)
```

## Команди запуску

Усі команди виконуються з кореневої директорії репозиторію (`cybersecurity-python-labs`).

### 1. Офлайн-аналіз із локального JSON-файлу (`--input`)
Запускає аналіз без звернення до мережі інтернет на основі збереженої відповіді NVD API:
```bash
python -m labs.lab04.main --cve CVE-2099-10001 --input labs/lab04/data/nvd_sample.json
```

### 2. Онлайн-запит до NVD API (без API-ключа)
Отримує актуальні дані про вразливість напряму з `[https://services.nvd.nist.gov/rest/json/cves/2.0](https://services.nvd.nist.gov/rest/json/cves/2.0)`:
```bash
python -m labs.lab04.main --cve CVE-2021-44228
```

### 3. Онлайн-запит до NVD API з використанням API-ключа (`NVD_API_KEY`)
Для підвищення лімітів запитів NVD API можна передати ключ через змінну середовища `NVD_API_KEY` (вона автоматично додається в заголовок `apiKey`):

* **Windows (PowerShell):**
  ```powershell
  $env:NVD_API_KEY="ваш_api_ключ"
  python -m labs.lab04.main --cve CVE-2021-44228
  ```
* **Linux / macOS (Bash/Zsh):**
  ```bash
  export NVD_API_KEY="ваш_api_ключ"
  python -m labs.lab04.main --cve CVE-2021-44228
  ```

### 4. Перегляд довідки CLI (`--help`)
Виводить опис усіх доступних прапорців командного рядка:
```bash
python -m labs.lab04.main --help
```

## Коди завершення програми (Exit Codes)

| Код | Потік виводу | Опис ситуації |
| :---: | :---: | :--- |
| **`0`** | `stdout` | Успішне виконання; у консоль виведено валідний JSON-звіт (включно зі статусами `not_found`, `rejected`, `insufficient_data`). |
| **`1`** | `stderr` | Помилка під час виконання: мережевий збій або таймаут NVD API, HTTP-помилка, неіснуючий локальний файл, некоректний JSON або порушення структури відповіді. |
| **`2`** | `stderr` | Помилка аргументів командного рядка: відсутній обов'язковий параметр `--cve` або його значення не відповідає формату `CVE-YYYY-NNNN...`. |
